Rift-GLUE
=========

**A GLUE-based genomic knowledge base for Rift Valley fever virus (RVFV)**

Overview
--------

Rift-GLUE is an open bioinformatics resource for the integration, analysis and interpretation of **Rift Valley fever virus (RVFV)** genome sequences.

Built using the **Genes Linked by Underlying Evolution (GLUE)** framework, Rift-GLUE provides a curated genomic reference dataset together with associated phylogenetic, geographical and epidemiological information. Rather than functioning as a simple sequence database or analysis pipeline, Rift-GLUE is designed as an evolving **genomic knowledge base** that supports comparative analyses of RVFV diversity and facilitates interpretation of newly generated virus genomes.

The project aims to provide a reproducible and extensible foundation for genomic surveillance of RVFV and to support research into the evolutionary history, emergence and spread of this important zoonotic pathogen.

* * * * *

Project goals
=============

Rift-GLUE seeks to:

-   curate a high-quality collection of publicly available RVFV genome sequences
-   standardise and enrich associated metadata
-   establish robust reference alignments and phylogenetic frameworks
-   define and characterise viral lineages
-   integrate genomic information with outbreak, host and geographical context
-   provide a reusable platform for comparative evolutionary analyses
-   support ongoing genomic surveillance as new sequences become available

* * * * *

Philosophy
==========

Genomic analyses are often performed as isolated studies in which datasets are assembled, analysed and then discarded.

Rift-GLUE instead adopts an **information systems approach**.

Rather than repeatedly rebuilding datasets for individual analyses, the project maintains a continually curated representation of current knowledge about RVFV. As new sequences become available they can be incorporated into an existing evolutionary framework together with their associated biological context.

This approach allows analyses to build upon one another over time, transforming individual investigations into an expanding body of reusable knowledge.

* * * * *

What the project contains
=========================

The repository contains infrastructure for managing and analysing RVFV genomic data, including:

-   curated reference sequences
-   genome feature annotation
-   sequence alignments
-   phylogenetic reference datasets
-   lineage definitions
-   genome variation analyses
-   standardised isolate metadata
-   geographical information
-   host information
-   outbreak-associated metadata
-   reproducible analysis workflows

* * * * *

Scientific objectives
=====================

The long-term scientific goals of Rift-GLUE include:

-   reconstruction of RVFV evolutionary history
-   characterisation of viral lineage diversity
-   comparative analysis of historical outbreaks
-   investigation of virus movement across geographical regions
-   identification of lineage-defining mutations
-   integration of genomic and epidemiological evidence
-   support for genomic surveillance and outbreak response

* * * * *

Why GLUE?
=========

GLUE provides an extensible data model for representing genomic information together with its biological context.

Within Rift-GLUE, genome sequences are linked to:

-   evolutionary relationships
-   genome annotations
-   sequence variation
-   host species
-   geographical origin
-   sampling dates
-   publications
-   outbreak information

This allows new virus genomes to be interpreted within an existing body of curated knowledge rather than analysed in isolation.

* * * * *

Repository status
=================

Rift-GLUE is currently under active development.

The initial focus is on establishing a comprehensive curated dataset of publicly available RVFV genomes together with reproducible phylogenetic reference datasets. Subsequent development will expand the associated epidemiological and ecological knowledge base and provide additional analytical capabilities for comparative outbreak investigation and genomic surveillance.

* * * * *

Future directions
=================

Planned developments include:

-   expanded metadata curation
-   lineage nomenclature
-   automated phylogenetic placement of new genomes
-   mutation annotation
-   comparative outbreak analysis
-   integration of ecological and environmental metadata
-   interactive visualisation tools
-   interoperability with genomic surveillance initiatives including **GenPath Africa**
